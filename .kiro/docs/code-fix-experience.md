# 代码修复经验库

> **用途**：每次 bug 修复后记录完整经验，避免重复排查。
> **格式**：`### E-xxx 问题简述` → 场景 / 症状 / 排查弯路 / 根因 / 修复 / 关联
> **写入时机**：每次 bug 修复后
> **核心价值**：排查弯路（"试过但没用"的方案）是避免重复踩坑的关键
> **与 self-evolving-rules 的区别**：experience 是案例（"遇到了什么"），rules 是规则（"以后怎么做"）

## 经验条目模板

```markdown
### E-xxx 问题简述
- **场景**：什么操作下发生
- **症状**：观察到的现象
- **排查弯路**：试过但没用的方案（核心价值）
- **根因**：真正的原因
- **修复**：如何解决（commit hash）
- **关联**：相关规则 R-xxx 或 commit
```
